# Prestige Optics — eyeglasses try-on

Angular storefront demo with MediaPipe iris-based virtual try-on.

## Open in StackBlitz

1. Open:

   https://stackblitz.com/github/ynachar/prestige-optics-tryon

2. Wait for `npm install` + `ng serve` (preview on port **4200**).
   If the preview hangs on “Booting WebContainer”, refresh once or open the **Ports** panel and select **4200**.

Sign-in with GitHub account `ynachar` is optional for this public repo.
## Cursor → StackBlitz workflow

```bash
cd ~/DEV-Github/prestige-optics-tryon
# edit files in Cursor…
git add -A && git commit -m "your message" && git push
```

`origin` is https://github.com/ynachar/prestige-optics-tryon (`main`).  
Then refresh the StackBlitz tab (or reopen the link above).

## Local

```bash
npm install
npm start
```

App runs at http://localhost:4200/
